# early-discussions/

Raw, exploratory discussion notes from before implementation — the source
material behind `research/objectives.md` and the initial phases in
`.claude/tasks/`. Kept as-is, not polished: this is where to look for the
reasoning behind a decision that `objectives.md` states as settled, or to
recover context on something that was considered and dropped.

Not meant to be read standalone by someone without project context, and
never promoted into `docs/` as-is — if a discussion here produces a
resolved conclusion worth sharing, write it up fresh in `docs/` per
[`docs-writing-guide.md`](../../context/docs-writing-guide.md).

**Naming:** `topic_name.md`, one file per exploratory thread.
